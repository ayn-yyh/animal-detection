## 📖 项目简介

本项目基于 **YOLOv8** 深度学习算法，构建了一套珍稀保护动物智能检测系统。系统能够自动识别 8 类中国珍稀保护动物，并提供实时视频检测、单图检测、批量检测等多种交互方式。前端采用响应式设计，支持实时统计信息展示、截图保存和结果导出，形成完整的"用户交互→模型推理→结果展示"闭环。

## ✨ 核心功能

- **实时视频检测**：连接本地摄像头，实时识别画面中的保护动物，显示检测框、类别标签和置信度
- **单图检测**：上传单张图片，自动识别并标注动物位置，展示检测结果和科普信息
- **批量检测**：多张图片批量处理，支持导出 CSV 格式检测结果
- **动物科普**：点击动物卡片，查看详细介绍和示例图片
- **统计看板**：实时显示检测数量、平均置信度、最高置信度、检测类别等关键指标
- **截图保存**：一键截取当前检测画面并保存至本地
- **阈值调节**：支持实时调节置信度阈值和 IOU 阈值，优化检测效果

## 🚀 本地运行

```bash
# 克隆项目
git clone https://github.com/ayn-yyh/animal-detection.git
cd animal-detection

# 创建虚拟环境
conda create -n yolo python=3.10
conda activate yolo

# 安装依赖
pip install -r requirements.txt

# 运行
python app.py

访问：http://localhost:5000
```

## 📊 模型配置

| 配置项 | 参数 |
|--------|------|
| 检测类别 | 8 类 |
| 数据集 | 每类约 200 张 |
| 置信度阈值 | 0.25（可调） |
| IOU 阈值 | 0.45（可调） |
